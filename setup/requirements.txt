# TensorFlow and Keras are deliberately absent. The gesture MLP used to run
# under Keras; gesture_mlp.py now does the forward pass in numpy, reading the
# weights out of landmark_gesture_model.h5 with h5py. Nothing the server runs
# imports TensorFlow any more, and leaving it installed costs ~400 MB of RSS
# in the server process, because mediapipe imports it unconditionally for a
# documentation decorator (mediapipe/tasks/python/core/optional_dependencies.py,
# which falls back to a no-op when the import fails).
#
# h5py is therefore a DIRECT requirement now, not a leftover TensorFlow
# dependency -- do not let a dependency cleanup take it with TF.
#
# Only tests/test_gesture_mlp.py still wants TensorFlow, to check the numpy
# forward pass still matches Keras exactly. It skips that comparison when TF
# is missing. Install `tensorflow-cpu-aws==2.15.1` and `keras` into a
# development environment -- not the server's -- and re-run that suite after
# retraining the model.
